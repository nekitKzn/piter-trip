# piter-trip

Интерактивная карта поездки в Санкт-Петербург на 24–27 сентября 2026 года.

## Сайт

После включения GitHub Pages сайт будет доступен по адресу:

https://nekitkzn.github.io/piter-trip/

## Содержимое

- `index.html` — весь сайт: интерфейс, расписание, карта и маршруты.
- `PLAN.md` — полный план поездки в удобном текстовом виде.

Сайт статический: сборка, Node.js и база данных не требуются.

## Публикация

GitHub → Settings → Pages → Build and deployment → Deploy from a branch:

- Branch: `master`
- Folder: `/ (root)`

После сохранения GitHub автоматически публикует каждое изменение в ветке `master`.

## Работа через ChatGPT

Можно написать в чате, например:

> На субботу перенеси завтрак на 9:30 и добавь новую кофейню.

После изменения `index.html` и отправки коммита в `master` опубликованный сайт обновится автоматически.
